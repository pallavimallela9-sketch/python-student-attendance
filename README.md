# Student Attendance Management System

This Python program manages student attendance using a menu-driven system. It allows users to add students, mark attendance, view attendance records, search for students, and generate an attendance summary.

## Features

* Add new students
* Mark students as Present or Absent
* View individual attendance records
* Calculate attendance percentage
* Search students using student ID
* Display overall attendance summary
* Menu-driven interface

## Technology Used

* Python

## Concepts Used

* Dictionaries
* Nested dictionaries
* `while` loop
* `for` loop
* Conditional statements
* String methods
* Arithmetic operations
* User input
* Menu-driven programming
